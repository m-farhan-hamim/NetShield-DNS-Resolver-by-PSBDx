NetShield is a local DNS resolver, ad/tracker sinkhole, and real-time
traffic monitor for Android.

Features:
* Two operation modes: a device-wide local VPN sinkhole, or a local UDP
  DNS server on 127.0.0.1 for custom apps/routers.
* DNS-over-HTTPS, DNS-over-TLS, and plain UDP upstream resolvers.
* Custom and built-in blocklists for ad/tracker sinkholing, with pause
  controls (5/15 minutes) and per-app split tunneling.
* Real-time traffic dashboard, live query logs, and per-domain rules.
* Quick Settings tile and a home-screen widget to toggle protection
  with a single tap.
* Import your own OpenVPN/WireGuard server configs to manage alongside
  the resolver (importing and managing profiles only for now - no
  bundled server list, and tunneling through them is not yet
  implemented).

No ads, no analytics, no tracking, no non-free dependencies.
